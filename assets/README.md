# Site artwork

## Generated brand mark

`naam-jaap-logo.png` is the original generated image. `icon-192.png`, `icon-512.png` and `favicon.png` are resized PNG exports of that same mark. The header, fallback personal cover, favicon and installable app use these assets. Original output was copied into this repository; no runtime asset depends on a home-directory path.

Created on 19 September 2026 using the built-in image generation tool, then resized with macOS `sips`. No external image API or CLI fallback was used.

Final prompt:

> Use case: logo-brand. Create one square app logo for Naam Jaap, a calm Hindu mantra practice and vratha tracker. A single elegant ivory lotus cradling a small glowing amber diya flame, with a subtle circular mala bead outline, centered on a deep warm terracotta background. Restrained clean geometric flat vector-like design, distinct at favicon size, generous safe margin, high contrast, no gradients or tiny details, no lettering, no watermark. This single mark will serve as both site logo and installed app icon.

## Practice illustrations

`ganapati.svg`, `rama.svg`, `hanuman.svg`, `shiva.svg`, `gayatri.svg` and `durga.svg` are original code-drawn vector symbols in a matching terracotta/ivory palette. They depict an elephant face, bow and arrow, gada, trident/crescent, sun with an open book, and lotus/trident respectively. They are symbolic illustrations, not depictions of sacred iconography claimed to be authoritative.

The images are decorative beside a visible practice name, with empty alternative text to avoid repeating that label. A personal uploaded cover is also decorative; reading-sheet images retain their filenames as labels and are accompanied by optional user-entered text.
